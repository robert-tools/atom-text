# 🗂️ @robert.tools/atom-text

A component to provide text elements.

## 📜 Usage

### 🟢 Installation

```bash
npm install @robert.tools/atom-text
```

### 📝 Sample usage

#### prerequisites

- define css variables

#### Template

Use the text component as shown below:

```html
{{ component("atom/text", {}) }}
```

#### CSS

Use the basic styling

```css
@import '@robert.tools/atom-text/index.css';
```

#### TypeScript

Include TypeScript by importing the component

```typescript
import * as AtomText from '@robert.tools/atom-text';
```
